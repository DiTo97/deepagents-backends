GitHub Pages deployment

How this site is published

  1. 1. Benchmark results are committed to benchmark/results/latest.json.
  2. 2. Static assets live in benchmark/web/ and read the latest JSON at runtime.
  3. 3. The pages.yml workflow copies the web assets and results into a Pages artifact.
  4. 4. A push to main or a manual dispatch republishes the dashboard.
Tip: update the benchmark README with uv run python benchmark/run.py --manage-services --write-readme, then let the Pages workflow publish the visual dashboard.
