# S3 Backend

`S3Backend` stores files in S3-compatible object storage such as AWS S3 or MinIO.

## Config

Use `S3Config` with:

- `bucket`
- `prefix`
- `region`
- `endpoint_url`
- `access_key_id`
- `secret_access_key`
- `use_ssl`

## Local development

- Service: MinIO
- Ports: `9000` (API), `9001` (console)
- Test credentials: `minioadmin / minioadmin`

## Notes

- Virtual paths map to S3 keys under `{prefix}/...`.
- `awrite()` fails when the object already exists.
- `upload_files()` and `download_files()` operate on raw object bytes.
